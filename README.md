# 2026

프로젝트 개발을 위한 기본 저장소입니다.

## 개발 환경

- Codex 클라우드 환경의 저장소 경로: `/workspace/2026`
- 기본 브랜치: `main`
- 현재 필요한 도구: Git

현재 애플리케이션 코드와 외부 의존성은 없습니다. 별도 설치나 서버 실행은 필요하지 않습니다.

## 개발 시작

프로젝트 목적과 사용할 언어·프레임워크를 정한 뒤 다음 항목을 추가합니다.

1. 애플리케이션 코드와 의존성 선언 파일
2. 재현 가능한 설치를 위한 의존성 잠금 파일
3. 실행·빌드·테스트 명령과 사용 방법
4. 필요한 환경 변수의 예시 파일(실제 비밀 값은 제외)

인증 정보와 API 키는 저장소에 커밋하지 말고 환경 설정을 통해 관리합니다.
